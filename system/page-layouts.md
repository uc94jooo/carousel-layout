# 任務實例庫：思考力養成輪播設計系統

**定位（2026-07-28 改制）**：本檔不是「頁型目錄」，是**任務實例庫**——每條以
「溝通任務」為主鍵（勾住第一眼、立知識錨點、情境重現…），下面的區塊結構只是
「這個任務曾經成功的一種解法」。**結構可重排，任務才是不變的**：堆疊順序、頁標
位置、物件檔位都可以按內容重新組裝（見下方組裝原則），照抄實例則是最穩的捷徑。

**新增政策**：預設不新增實例；只有當某次組裝解掉了**庫裡沒有的新任務**，才問
使用者要不要存一條（存不存、叫什麼名字都由使用者裁決）。判準是「新任務」，
不是「結構重複」——結構的排列組合無限，任務有限。

元件代號（C1～C23）與尺度檔位參照 [components.md](components.md)。
畫布：1080 × 1350 px。所有頁型底色 `--bg-page`，底部固定 C13 頁尾。

## 組裝原則（物件自組時的疊法，2026-07-28 定）

- **順序跟著敘事節拍**：鉤子在前、展開在中、收束錨在尾——節拍由內容定，不是由習慣定
- **頁標是物件不是欄位**：可放開場、中場（轉場錨）、收尾（收束錨），無頁標合法
  （觸發條件見 SKILL.md 第 2 步）；行數 1～3 行皆可，能少就少
- **一頁一個主角**：全頁或半頁物件最多一個當主角，其餘物件降為配件（中塊以下）
- **密度分工**：初稿允許字少頁鬆＋大物件（保守是預設不是缺陷）；裁決後的文字合併
  與物件降檔是標準動作，不算返工
- 留白規則、字數預算照舊——見 design-tokens.md 版面通則，不在此重抄

## L1. cover 封面頁

**用途**：整組輪播的第一張，3 秒內讓人決定要不要往下滑。

**區塊結構**：
1. C2 系列標籤
2. 主標（`--text-hero`，核心概念詞加 C1 螢光筆）
3. C3 副標分隔線（一句話立論，常用「A ≠ B」句式）
4. 主插畫（雙人對話場景或單一象徵物，可搭 C4 對話框）
5. C13 頁尾

**內容規則**：主標 4～8 個字。副標是全篇論點的一句話濃縮。插畫預告內文情境。

**變體 L1b（雙行標題版）**：主標降為 88px、跨兩行，適合「數據反差鉤子」型封面（例：獲得 37 個大獎的設計／讓輕生行為暴增 6 倍），螢光筆標在反轉數據上；副標可用 ✦ 夾核心名詞。單行裝得下就用標準版，說完整句鉤子才用雙行版。

## L2. hook-dialogue 情境提問頁

**用途**：第二張。用讀者自己遇過的情境釣出「對，這就是我」，結尾丟懸念引導翻頁。

**區塊結構**：
1. 頁標（提問句式：「你有沒有遇過這種狀況？」）
2. C5 情境卡 × 2（兩個平行案例）
3. 收尾引導句（含 C1 標記的懸念詞＋箭頭「→」）
4. C13 頁尾

**內容規則**：兩張情境卡必須是不同關係、同一結構的案例。收尾句必須製造「想知道為什麼」的缺口。

## L3. concept 概念頁

**用途**：講解一個概念的標準頁。文字為主、插畫為輔。

**區塊結構**（兩種變體）：
- 3a 標準式：頁標 → 插畫 → 內文段
- 3b 三明治式：導入句 → 插畫 → 結論段

**內容規則**：一頁只講一個概念。內文 3 行以內，裝不下就拆頁。

## L4. image-lead 視覺主導頁

**用途**：讓插畫當主角的頁，用於情緒轉折或畫面感強的比喻。

**區塊結構**：
1. 大幅插畫（佔頁面上方約 2/3）
2. 短說明文字（1～2 行，可含 C1 標記）
3. C13 頁尾

**內容規則**：文字是圖說，不是論述。超過 2 行就該用 L3。

## L5. scene-full 滿版情境頁

**用途**：沉浸式情境重現，插畫鋪滿整頁當背景。

**區塊結構**：
1. 滿版插畫背景（可用 `--bg-cream` 大色域）
2. 疊在畫面上的文字卡（白底圓角小卡，位置避開插畫主體）或 C4 對話框
3. C13 頁尾（疊在畫面底部）

**內容規則**：文字卡內容 3 行以內。此頁型是全系列唯一允許插畫超過 1/3 面積的頁。

## L6. two-cols 對照頁

**用途**：兩個對象或兩種做法的平行比較，比完收一個共同結論。

**區塊結構**：
1. 頁標（點出兩者共同的錯誤或共同的處境，關鍵詞加 C1）
2. C6 對照卡 × 2
3. （可選）C10 橫向流程條——把對照背後的機制一行講完
4. 底部結論句（可含 C1 標記）
5. C13 頁尾

**內容規則**：結論句必須同時涵蓋兩張卡，不偏袒任一邊。

## L7. fact 定律重點頁

**用途**：拋出理論、定律、金句的權威頁。全篇的「知識錨點」。

**區塊結構**：
1. 頁標（定律／概念名稱）＋ 英文原名（`--text-caption`，`--ink-soft`）
2. C8 引言黑線框（定律內文，關鍵詞加 C1）
3. C9 icon 三欄組（落地到 2～3 個生活領域）
4. 底部延伸句（把定律接回主題，可含 C1）
5. C13 頁尾

**內容規則**：引言必須忠於原典或明確標示改寫。icon 三欄的領域按「離讀者最近 → 最遠」排序。

## L8. case-stack 案例堆疊頁

**用途**：用 2 個具體案例證明同一個機制，製造「原來到處都是」的效果。

**區塊結構**：
1. 頁標（把兩個看似無關的對象綁在一起的句子，可跨 3 行）
2. 白卡 × 2，每卡左側為「數字或圖」標記區（C7 編號圓圈、案例 icon 插畫，可單用或並用、直向堆疊），右側為純文字區：案例小標＋案例內文（含 C1 標記）
3. 收尾引導句（指向下一頁的理論或結論，帶「→」）
4. C13 頁尾

**內容規則**：兩個案例必須一遠一近——一個歷史或他方案例、一個讀者自身案例。

## L9. flow 流程頁

**用途**：超過 3 步的因果鏈或步驟，整頁直式呈現。

**區塊結構**：
1. 頁標
2. 直式流程：標記槽（C7 編號圓圈或 icon 插畫，同頁擇一）＋ 步驟短句（文字永遠在右欄），節點間用向下箭頭連接，3～6 節；步驟越多，模板自動縮小圓圈與字級
3. （可選）底部一句話點出流程的關鍵轉折
4. C13 頁尾

**內容規則**：每節短句 10 字以內。3 步以內用 C10 橫條收進其他頁型即可，不開整頁。標記用編號還是 icon 看內容：有順序感用編號，講故事場景用 icon。

## L10. summary-cta 總結行動頁

**用途**：最後一張。三點總結＋留言邀請，收束並開啟互動。

**區塊結構**：
1. 頁標（「記住這三件事就好」式的收束句）
2. 條列 × 3～6：C7 編號圓圈＋一句話重點（每句一個 C1 標記），點與點之間用細虛線連接；超過 3 項時模板自動縮小字級與圓圈（3 項仍是標準）。條列右側可放一個直式插畫位（可選，約 1/3 寬，如思考中的人物，參考：眼鏡蛇效應系列頁 7）
3. C11 CTA 黃條（留言邀請，給一個具體好回的題目）
4. C13 頁尾

**內容規則**：三點必須是前面頁面講過的內容，不出現新概念。CTA 問題要低門檻（人人有故事可答）。

## 敘事順序建議（非強制）

標準八頁組合：
L1 封面 → L2 情境提問 → L6 對照 → L9 或 C10 流程 → L7 定律 → L8 案例 → L10 總結。

原則：先情境（讀者的痛）→ 再機制（為什麼會這樣）→ 再理論（背後的定律）→ 再案例（到處都是）→ 最後收行動。L3／L4／L5 視內容需要穿插。

## L12. story-annotated 敘事＋分析層頁

**用途**：故事型輪播的主力頁。上半原文敘事零刪減照排，下緣一排分析標籤把該段的機制攤開——故事在上、X 光片在下，洞察由讀者自己完成。

**注意**：本頁型**沒有新元件**，是純既有元件的新組裝——分析層就是 L7 用的那個 C9 三欄（或 C18 膠囊列），新的只有「敘事區不限行數＋分析層墊底」這個組合方式。

**區塊結構**：
1. 頁標（可無；有的話用敘事引導句，例：「他當時是這樣說的：」）
2. 敘事區：原文段落全寬照排（`--text-body`），段落間留呼吸間距，螢光筆照 C1 規則
3. 分析層：C9 三欄（圖＋分析標籤）或 C18 膠囊列，貼頁面下緣、頁尾之上
4. C13 頁尾

**內容規則**：敘事區 6～9 行為舒適帶（全寬 20 字/行），文字是版面主角，**不刪減原文**——L3「內文 3 行以內」的限制不適用於本頁型。分析層標籤必須寫機制、不准只寫名詞（例：「強調缺點：容易髒」，不是「白色包包」）。分析層佔高 ≤1/4，可省略（純敘事頁）。

**拆頁準則**：拆頁點跟著敘事節拍走（懸念、反諷、punchline），不是跟著版型容量走；每頁結尾應是一個讓人想翻頁的鉤子。

## L13. scale-contrast 大字小字頁

**用途**：用字級差表演「放大／縮小」的取景操作——讀者必須瞇眼湊近讀小字，頁面本身重演了這個概念。

**區塊結構**：
1. 宣稱句：`--text-hero` 或 `--text-h1` 鋪上半頁（關鍵詞可加 C1）
2. 但書句：`--text-caption`、`--ink-soft`，縮在下方角落
3. （可選）一行點破句（`--text-body`）
4. C13 頁尾

**內容規則**：大小字級差至少跨兩級；但書句必須原文照錄，不改寫；但書句可用比
`--text-caption` 更小的 22px（比頁尾還小，模擬瓶身小字，是刻意設計）；全頁字級仍 ≤3 個。與 C6b 的分工：C6b 用卡片並列兩份說法，L13 用字級直接重演壓制關係，一組輪播兩者擇一，不重複使用同一素材。

## L11. outro-profile 自介收尾頁

**用途**：故事型輪播的最後一張。用一個反問把內容拉回讀者身上，接留言邀請，下半部放自介卡轉追蹤。

**區塊結構**：
1. 雙行標題區（`--text-h1`，以 2 行為準，關鍵詞加 C1。例：寫完這篇，我學到什麼？）
2. CTA 文字區（彈性高度，吃掉中段留白：留言邀請、引導提問、行動指令、下集預告，可多行）
3. C16 自介卡
4. C13 頁尾（必備，內容改用關注行：關注 @uncle.johs　讓行銷更有意思，取代預設的「IG @uncle.johs」）

**內容規則**：反問必須是讀者自己的經驗題，不是知識題。與 L10 的分工：知識型輪播用 L10（三點總結收束），故事型輪播用 L10 精簡版＋L11，或直接 L11 收尾。
