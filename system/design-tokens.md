# Design Tokens

畫布基準：1080 × 1350 px（IG 直式 4:5）。本檔為 token 唯一事實來源。

## 0. 主題制（2026-07-23 模組化）

主題定義**不在本檔**，一個主題一個檔案，位於技能根目錄 `themes/`（色值、定位、啟用方式都寫在各檔檔頭註解）。每組輪播開工單時擇一主題，整組一致。

目前主題：gray（螢光筆灰色，預設）／warm（螢光暖色）／pink（螢光粉色）。

**新增主題 SOP（不動任何主檔）：**
1. 在技能根目錄 `themes/` 新增 `<名>.css`：檔頭註解寫規格（名稱／定位／色值），內容定義 `.page.<名> { --bg-page; --bg-cover; --grid-line; }`
2. 在 `themes/themes.css` 加一行 `@import url("<名>.css");`
3. 若新主題內頁要預設格子紙，在 base.css 的格線規則選擇器加上 `.page.<名>:not(.cover)`
4. 同步 assets 到使用中的輪播組，用共用腳本重建試衣間（system/templates/build-board.py）

其餘 token（黑白米黃、字型、字級、間距）為主題共用，仍在 tokens.css／本檔。
方格紙規則：暖、粉內頁預設帶格（封面除外，`.no-grid` 退出）；灰為選配（`.grid-paper`）。
輸出選配（主題 × 線框 `.lined` × 格線）不變。

## 1. 色票

### 基底色

| Token | 色值（估） | 用途 |
|-------|-----------|------|
| `--bg-page` | `#EAEAE8` | 頁面底色，淺暖灰。內頁的預設背景 |
| `--bg-cover` | `#DCDCDA` | 封面（L1）專用底色，Mac 鋁銀感，比內頁深一階，讓第一張在動態牆上更有份量 |
| `--bg-card` | `#FFFFFF` | 白色資訊卡、對照卡背景 |
| `--bg-cream` | `#F6F1E4` | 米色對話卡、情境卡背景 |
| `--ink` | `#1C1C1A` | 主文字色、線框色。不用純黑 `#000` |
| `--ink-soft` | `#55554F` | 次要文字（英文小標、輔助說明） |

### 強調色

| Token | 色值（估） | 用途 |
|-------|-----------|------|
| `--highlight` | `#F9E952` | 螢光筆黃。唯一的強調色，用於關鍵詞底色 |

| Token | 色值（估） | 用途 |
|-------|-----------|------|
| `--illust-skin` | `#F2E3D5` | 人物膚色 |
| `--illust-hair` | `#6B5647` | 人物髮色（棕色系） |

## 2. 字型

| 層級 | 字型 | 字重 | Fallback |
|------|------|------|----------|
| 標題 | 金萱 | 濃（最重的可用字重） | Noto Sans TC Black → sans-serif |
| 內文 | 金萱 | 中～粗 | Noto Sans TC Medium → sans-serif |
| 英文小標 | 金萱（或系統無襯線） | 粗 | Arial Bold |

使用者持有金萱授權字體。HTML 模板以 `@font-face` 載入本機字型檔。

### 字級層級（1080 寬基準）

| Token | 大小 | 行高 | 用途 |
|-------|------|------|------|
| `--text-hero` | 128px | 1.25 | 封面主標（一頁只有封面用） |
| `--text-h1` | 61.33px（46pt） | 1.3 | 各頁大標 |
| `--text-h2` | 48px | 1.4 | 區塊小標、卡片標題 |
| `--text-body` | 38px | 1.6 | 內文、卡片內文 |
| `--text-caption` | 30px | 1.5 | 輔助說明、icon 下方標註 |
| `--text-footer` | 26px | 1 | 頁尾簽名 |

規則：
- 每頁最多出現三個字級。
- 大標一行以 8～10 個中文字為上限。
- `--text-h1`（61.33px／46pt，2026-08-02 改為固定值）：不分單行、雙行、三行，一律套用同一字級，不再依行數降級。
- 字距（letter-spacing）標題 0.02em，內文 0.05em。

| `--page-pad` | 72px | 頁面四邊留白 |
| `--block-gap` | 48px | 主要區塊之間的垂直間距 |
| `--card-pad` | 40px | 卡片內部留白 |

| `--radius-pill` | 999px | 標籤膠囊圓角 |

## 4. 版面通則

- 頁面永遠是 `--bg-page` 淺暖灰打底，內容置於安全區（四邊 72px 內）。
- 對齊以「置中軸」為預設；純文字重點頁（fact）可改左對齊。
- 每頁底部固定頁尾：`IG @uncle.johs`，置中，`--text-footer`，`--ink-soft`。
- 陰影原則上不用；層次靠色塊（白卡、米卡）和線框做，不靠投影。
- 一頁一件事：每頁只承載一個論點或一個情境，資訊裝不下就拆頁，不縮字。
- 頁標非必備（2026-07-23 定）：不強制每頁都放標題。視覺主導、滿版情境、金句收束等頁型可無頁標直接進內容；無頁標時內容區自然上移或均分留白，不留「標題洞」。工單的頁標欄寫「無」即可。
- 斷行規則（2026-07-22 定）：行尾不准剩 1～2 個字。窄欄文字有「每行字數預算」，寫文案時照預算斷句或改寫，超預算改寫句子而非縮字級。**預算一律以最窄選配組合（有框 `.lined`，內容寬 872px）為準**：全寬內文約 20 字／行（無框可到 24，但按 20 寫才能通吃選配）、L8 案例卡內文約 22 字／行、L6 對照卡內文約 10 字／行、L10 帶圖條列約 9～13 字／行（隨項數縮放增加）。模板另以 CSS `text-wrap: pretty`（內文）與 `text-wrap: balance`（標題）兜底，但預算是第一道防線。
- 留白規則（2026-07-22 定）：多餘的垂直空間不准集中成一個洞。有插畫位的頁，插畫位自動長高吃掉留白、文字區塊間距固定；純文字頁把留白均分到區塊之間；內容已填滿的頁與刻意留白的頁（如 L11 中段）不套此規則。
- 座標單位換算（2026-08-02 定）：使用者給版面座標／尺寸時，若數字明顯偏小（例如個位數十至數百，且換算後與 1080×1350 畫布的比例吻合），優先判讀為 **pt**（PPT／Keynote 慣用單位），換算 `px = pt × 4/3`（96dpi 標準；畫布 1080×1350px 對應 810×1012.5pt，可用此比例反查驗證）。單位不確定時，先跟使用者確認，不憑感覺套用；已用某單位算完一版又被使用者用另一組數字追問換算，視為在糾正單位判讀，需重新套用並修正既有頁面。
- 自訂內容欄（2026-08-02 定）：使用者指定內容欄的 X 與寬度取代預設 `page-pad`（72px）時，除非使用者明講要不對稱（例如刻意拉大單側留白做設計感），否則左右邊界預設對稱，即寬度 = 畫布寬 − 2×X；同一頁其餘物件（金句卡、引言黑線框、循環圖等圖表）一律對齊同一欄的左緣與寬度，圖表類物件依欄寬等比縮放並置中，不各自為政。
- spacer 置中規則（2026-08-02 定，修正 P3/P7 實戰教訓）：`.spacer`（`flex:1`）只能包在**整組內容的外側**（最多一頭一尾，用來把整組往版面中央推），絕對不能夾在同一群組裡兩個需要維持固定視覺關係的物件之間（例：一段引導文字接一張圖表／圖列——這兩者的間距要穩定，不能隨頁面剩餘空間縮放）。群組內部一律用固定值：一般段落間用 `--block-gap`（48px），**文字轉場到圖片列／情境圖列**這種換資訊層級的節點用加大的 `--section-gap`（80px），不要沿用段落間距。判斷準則：先把整頁物件按「敘事群組」分堆（例：`[引導文字＋圖表]` 是一堆），堆內固定間距排好，最後才用頭尾 spacer（或 `.page.center` + `justify-content:center`）把整堆置中；事後若調動群組內物件順序（例如把文字從圖表下方移到上方），要連帶檢查固定間距與 spacer 位置是否還在群組外側，不能只搬物件不搬間距邏輯。
